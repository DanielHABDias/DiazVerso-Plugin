# Nox canônico

Nox.png é a referência visual fornecida pelo criador para o Diazverso. Não editar nem substituir esta imagem. Integridade, dimensão e origem estão em assets/manifest.json.

Preservar silhueta, proporções, cores, olhos, roupa, acessórios e linguagem visual. Novas poses precisam de comparação visual real com a referência e da verificação em skills/diazverso-nox/scripts/character_lock.py. Um arquivo com nome parecido não comprova identidade.
